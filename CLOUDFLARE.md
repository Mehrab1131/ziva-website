# Cloudflare deployment

This project is a fully pre-rendered Astro static site.

It is deployed using **Cloudflare Workers Static Assets**, not the Astro
Cloudflare adapter and not SSR.

## Configuration

The repository contains `wrangler.jsonc` with:

- Worker/project name: `ziva-website`
- Static asset directory: `./dist`
- No `main` Worker entry point

The important part is:

```json
"assets": {
  "directory": "./dist"
}
```

This tells Wrangler to serve the files generated by Astro's static build.

## Local commands

```bash
npm install
npm run fetch-fonts
npm run build
npm run deploy
```

`npm run deploy` builds the static site and then runs Wrangler.

## GitHub / Cloudflare Workers Builds

Connect the GitHub repository to Cloudflare Workers Builds with:

- Production branch: `main`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

Do not add `@astrojs/cloudflare` or change `astro.config.mjs` to `output: "server"`.
The project must remain a static Astro site.

## Output

Astro generates the website in:

```text
dist/
```

Wrangler deploys that directory as Cloudflare Static Assets.
